# Contributing

Thanks for your interest. This repository is a portfolio, so changes are small and reviewed by the owner.

## Clone & Setup

```bash
git clone https://github.com/YanissAmz/getasolutions-portfolio.git
cd getasolutions-portfolio
```

There is no build step: the repository holds the README and the screenshots.

## Filing Issues

- Search the open issues first.
- One problem or request per issue, with a short title.
- For a mistake in the text or a broken link, quote the line and say what it should be.

## Branches

- `feature/<short-name>` for new content.
- `fix/<short-name>` for corrections.
- Never push to `main`: open a pull request from your branch.

## Commits

- Write commit messages in English, in the imperative, and say what changes and why
  (for example: `README: fix the broken link to the demo video`).
- Keep each commit to one change.
